# 🖼️ Our Gallery

A responsive image search website built with plain **HTML, CSS and JavaScript**. Search any topic, browse beautiful photos from the , view them in a full-size popup, and download them.


## ✨ Features

- 🔎 Search photos by any keyword (press **Enter** or click the search button)
- 🖼️ 12 images per page with **Previous / Next** buttons
- 🔍 Click any image to open it in a large popup preview
- ⬇️ Download the full-quality image with one click
- ❌ Close the popup with the cancel button
- 👋 Animated welcome screen before the first search
- 📱 Fully responsive: 3 cards per row on desktop, 2 on tablet, 1 on mobile
- 🚫 Handles empty searches and searches with no results

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, animations, media queries)
- JavaScript (ES6, `fetch`, `async/await`)
- [Unsplash API](https://unsplash.com/developers)



## 📖 How to Use

1. Type something in the search box, for example `mountains`
2. Press **Enter** or click the search icon
3. Use **Previous** and **Next** to move between pages
4. Click an image to open the popup
5. Click the download icon to save the image, or the ✕ to close
